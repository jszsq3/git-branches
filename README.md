# Git 分支

仿 IntelliJ IDEA Git 工具窗口的轻量 macOS 桌面应用：打开文件夹，管理它所在 Git 仓库的分支、提交日志和工作区改动。基于 Tauri 2 + React + TypeScript，所有操作都直接调用本机的 `git` 命令。

## 功能

- **多工作区**：顶部标签栏一个标签一个仓库，显示分支、改动数与合并/变基状态；⌘1–⌘9、⌃Tab 切换，⌘W 关闭，⌘O 打开文件夹，可拖动排序，启动时恢复上次打开的标签。不是仓库的文件夹可就地 `git init`。
- **分支树**：HEAD、本地、远端、标签；按 `/` 分文件夹，当前分支和收藏置顶，显示相对上游的 `↑领先 ↓落后`，上游已删除时标红；支持搜索。
- **分支操作**（右键或左侧工具栏）：检出、从此新建、更新（获取并快进到上游，非当前分支不用检出）、获取单个远端分支、与当前比较、合并到当前、把当前变基到它、推送 / 强制推送（`--force-with-lease`）、重命名、收藏、删除（未合并时二次确认强制删除）、删除远端分支。
- **提交日志**：彩色分支图，按提交信息、哈希、作者筛选；点分支树只看该分支；比较模式分别列出双方独有的提交和改动文件；键盘上下切换。
- **提交详情**：完整信息、父提交跳转、所在分支、改动文件列表，点文件在底部看差异，双击或右键用默认应用打开文件。
- **提交页**：冲突 / 已暂存 / 未暂存三组，逐个或全部暂存、取消暂存、还原；冲突可采用我方或对方版本、标记已解决；合并、变基进行中可继续或中止；提交、提交并推送，支持修改上次提交（⌘↩ 提交）。
- **获取、拉取、推送**：拉取先尝试快进，不行再询问是否合并拉取；切回窗口时自动刷新当前标签。
- **中 / EN 切换**：标签栏右上角切换界面语言，原生菜单栏同步切换，选择会被记住。
- **检查更新**：启动 3 秒后及每 6 小时静默检查一次，有新版本时顶部提示，可下载到“下载”文件夹并自动打开安装包，或跳过该版本；点右上角版本号或菜单“检查更新…”可手动检查。

## 开发

需要 Node.js、pnpm 和 Rust（本项目锁定兼容 Rust 1.88 的依赖版本）。

```bash
pnpm install
```

```bash
pnpm tauri dev
```

## 发布新版本

1. 修改 `src-tauri/tauri.conf.json` 的 `version`（更新检测按它与已发布版本比较）。
2. 打包 Apple 芯片版 DMG：

```bash
pnpm tauri build --bundles dmg
```

产物在 `src-tauri/target/release/bundle/dmg/GitBranches_<版本>_aarch64.dmg`。应用做了 ad-hoc 签名，未经 Apple 公证：别人首次打开时需在“系统设置 › 隐私与安全性”里点“仍要打开”。

3. 在版本管理后台（MyFlicker）新建版本，渠道选“稳定版”，上传 DMG、填写更新说明并发布。已安装的应用会在下次检查时提示更新。

更新接口与下载地址写在 `src-tauri/src/lib.rs` 的 `UPDATE_ENDPOINT`、`UPDATE_PROJECT`、`DOWNLOAD_PREFIX`；发布渠道是 `src/lib/update.ts` 的 `CHANNEL`。

## 结构

- `src-tauri/src/lib.rs`：执行 `git`、判断仓库状态文件、检查与下载更新、按语言重建菜单栏。
- `src/lib/`：读取引用、日志、状态、差异（`repo.ts`），分支图泳道布局（`graph.ts`），差异解析（`diff.ts`），界面文案与中英词典（`i18n.ts`），检查更新（`update.ts`）。
- `src/state/`：仓库状态与操作执行（`repo-context.tsx`）、弹窗与右键菜单（`dialogs.tsx`）、分支操作（`branch-actions.ts`）。
- `src/components/`：标签栏、更新提示、分支树、日志、详情、差异、提交页等界面。
- `src-tauri/icons/icon.svg`：应用图标源文件，改动后用 `pnpm tauri icon` 重新生成各尺寸。
