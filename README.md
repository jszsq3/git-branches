# Git 分支

仿 IntelliJ IDEA Git 工具窗口的轻量 macOS 桌面应用：打开一个文件夹，管理它所在 Git 仓库的分支、提交日志和工作区改动。基于 Tauri 2 + React + TypeScript，所有操作都直接调用本机的 `git` 命令。

## 功能

- **打开文件夹**：系统对话框选择文件夹，自动定位所在仓库；不是仓库时可就地 `git init`。记住最近打开的仓库，启动时回到上一个。
- **分支树**：HEAD、本地、远端、标签；按 `/` 分文件夹，当前分支和收藏置顶，显示相对上游的 `↑领先 ↓落后`，上游已删除时标红；支持搜索。
- **分支操作**（右键或左侧工具栏）：检出、从此新建、与当前比较、合并到当前、把当前变基到它、推送 / 强制推送（`--force-with-lease`）、重命名、收藏、删除（未合并时二次确认强制删除）、删除远端分支。
- **提交日志**：彩色分支图，按提交信息、哈希、作者筛选；点分支树只看该分支；比较模式分别列出双方独有的提交和改动文件；键盘上下切换。
- **提交详情**：完整信息、父提交跳转、所在分支、改动文件列表，点文件在底部看差异，双击或右键用默认应用打开文件。
- **提交页**：冲突 / 已暂存 / 未暂存三组，逐个或全部暂存、取消暂存、还原；冲突可采用我方或对方版本、标记已解决；合并、变基进行中可继续或中止；写提交信息后提交、提交并推送，支持修改上次提交（⌘↩ 提交）。
- 获取、拉取（先尝试快进，不行再询问是否合并拉取）、推送；切回窗口时自动刷新。

## 开发

需要 Node.js、pnpm 和 Rust（本项目锁定兼容 Rust 1.88 的依赖版本）。

```bash
pnpm install
```

```bash
pnpm tauri dev
```

打包成 `.app`：

```bash
pnpm tauri build --bundles app
```

产物在 `src-tauri/target/release/bundle/macos/GitBranches.app`。

## 结构

- `src-tauri/src/lib.rs`：唯一的 `git` 命令（在指定目录执行 git，返回退出码与输出）和 `path_exists`。
- `src/lib/`：读取引用、日志、状态、差异（`repo.ts`），分支图泳道布局（`graph.ts`），差异解析（`diff.ts`）。
- `src/state/`：仓库状态与操作执行（`repo-context.tsx`）、弹窗与右键菜单（`dialogs.tsx`）、分支操作（`branch-actions.ts`）。
- `src/components/`：分支树、日志、详情、差异、提交页等界面。
